# Bot de pedidos de camisetas

Bot inicial para Telegram.

## Variables de entorno

`TELEGRAM_BOT_TOKEN` = token privado entregado por BotFather.

## Comandos

- `/start`
- `nuevo pedido`
- `cierro pedido`
- `muestra el pedido`

## Render

Build Command:
`pip install -r requirements.txt`

Start Command:
`python bot.py`
